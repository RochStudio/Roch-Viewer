Roch Viewer 1.1.2 adds Linux: the same window and readings as on Windows, on Wayland and X11, with no driver to fetch.

- The window runs as you, and a small helper does the register reads as root. It enforces the project's rules itself: `/dev/mem` read-only, no RAM, no reset ports, and the same SMBus allowlists as on Windows.
- Linux asks for your password when the viewer opens, as Windows does with UAC. `sudo rochviewer setup` stops it asking, with a trade-off the [Linux guide](https://github.com/RochStudio/Roch-Viewer/blob/v1.1.2/docs/linux.md) explains.
- `rochviewer dump` writes every row as JSON, for bug reports and machines with no desktop.
- On Linux, a Radeon's live clocks, temperature, fan, power and memory use also read on Intel boards.

| Platform | Memory | Windows | Linux |
| --- | --- | --- | --- |
| Intel LGA1851 (Z890) | DDR5 | Yes | Yes, tested on hardware |
| Intel LGA1700 (Z690/Z790) | DDR5 and DDR4 | Yes | Yes, not yet tested on hardware |
| AMD AM5 (Ryzen 9000, with Ryzen 7000 experimental) | DDR5 | Yes | Yes, not yet tested on hardware |

**Windows:** download **RochViewer.exe** below. Windows 10/11 x64 is required; Python, .NET and Rust are not needed to run it. Obtain **inpoutx64.dll** separately from [Highresolution Enterprises](https://www.highrez.co.uk/downloads/inpout32/), place it beside the executable, and accept the administrator prompt when opening the viewer. The driver is not bundled.

**Linux:** download **RochViewer-1.1.2-linux-x86_64.tar.gz** below, unpack it, and run `./rochviewer install` in the folder it unpacks to. It needs glibc 2.35 or newer, which means Ubuntu 22.04, Debian 12, Fedora 36 or anything since. Rust and a driver are not needed.

Readings depend on hardware, BIOS and access.

Validation: The automated tests passed on both systems. GitHub Actions completed the tests and release builds for both systems. On Linux, the viewer was run on a Gigabyte Z890 AORUS TACHYON ICE with a Core Ultra 7 270K Plus, DDR5-6000 and two RX 7900 XTs, with its readings checked against the kernel's own. LGA1700, AM5 and NVIDIA have not been run on Linux hardware. Live readings on Windows were not revalidated across every supported platform.

**SHA256SUMS.txt** contains both packages' SHA-256 checksums.
