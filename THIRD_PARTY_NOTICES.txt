Third-party components
======================

inpoutx64.dll / inpoutx64.sys  (NOT distributed with this project)
------------------------------------------------------------------
Roch Viewer needs a low-level access driver to read physical memory, PCI
configuration space and I/O ports. It uses inpout32/64 by Highresolution
Enterprises (www.highrez.co.uk), which reports:

  Copyright (c) 2008 Highresolution Enterprises.
  Portions Copyright (c) Logix4u.

Those files are deliberately NOT included in this repository or in any build
produced from it. They are third-party binaries under their own terms, and
this project is GPL-3.0; shipping them alongside it would make the combined
work something neither licence covers. Obtain them from the vendor and place
them beside the executable yourself -- see "Prerequisites" in README.md.

ZenStates-Core and ZenTimings  (followed, not bundled)
-------------------------------------------------------
Copyright (c) irusanov -- https://github.com/irusanov
GPL-3.0.

The AMD backend follows that work. Register numbers, bit fields and the bounds
applied to decoded values were taken from or checked against ZenStates-Core and
ZenTimings; the modules that do so carry a notice saying which, and the
comments beside the definitions say what came from where.

No source file from either project is included here. This project is
distributed under GPL-3.0, the same licence they use, which is what makes
building on them permitted -- and it is why the licence is GPL-3.0 rather than
something more permissive. Copyright in the parts that derive from that work
remains with its authors.

The files concerned:

  rochviewer/amd/agesa.py           rochviewer/amd/apob.py
  rochviewer/amd/fch_smbus.py       rochviewer/amd/power_metrics.py
  rochviewer/amd/profile.py         rochviewer/amd/smu_clocks.py
  rochviewer/amd/smu_power.py       rochviewer/amd/smu_voltages.py
  rochviewer/amd/timings.py         rochviewer/memory/ddr5_pmic.py
  rochviewer/memory/ddr5_telemetry.py

Three other files mention those projects without following them, and carry the
plain notice instead: ddr5_spd.py checks JESD400-5 offsets against them,
dimm_inventory.py borrows a label format, and ui/main.py a visual convention.

The MIT-licensed gnr-smu research project by Zorko was consulted for
independent Granite Ridge RSMU mailbox-address provenance. No gnr-smu source
is bundled, and the diagnostics that used it are not in this repository.

Reference tools
---------------
CPU-Z, HWiNFO, VoidTimings, ASRock Timing Configurator and MemTweakIt were
used as reference instruments: their readings were compared against this
project's on the same machine at the same moment to confirm that a register
had been located correctly. No source, header or data file from any of them
is included here, and none of them is required to run this.

Where a register was established by comparing against one of those tools, or
by diffing full captures across a controlled BIOS change, the evidence is
recorded in a comment beside the definition.
